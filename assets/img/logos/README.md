# /assets/img/logos — company logos

Drop each company logo here using the **exact filename** below. They appear automatically
in the Experience section (until then a styled text placeholder shows the company name).

| File | Company |
|------|---------|
| `stellantis.png` | Stellantis |
| `fyi.png` | FYI Digital Innovation |
| `renova.png` | Fundação Renova |
| `meridian.png` | Meridian Global Services |
| `ale.png` | ALE Combustíveis |
| `vale.png` | Vale S.A. |

**Tips**
- PNG with a transparent background works best (the slot has a light tint behind it).
- Roughly square or wide logos both work — they're scaled to fit inside a 96×96 box.
- Aim for ~256 px on the longest side.
