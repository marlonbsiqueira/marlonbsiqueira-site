# /assets/img/logos — company logos

Shown in the Experience chapter, one 96 × 96 tile per company (files are
192 × 192 for sharp rendering on retina screens). Each logo sits centred on a
white square (Meridian uses its own red), so all tiles read as one set.

| File | Company |
|------|---------|
| `stellantis.webp` | Stellantis |
| `fyi.webp` | FYI Digital Innovation |
| `renova.webp` | Fundação Renova |
| `meridian.webp` | Meridian Global Services |
| `ale.webp` | ALE Combustíveis |
| `vale.webp` | Vale S.A. |

To replace one, export a 192 × 192 WebP/PNG with the same name and update the
`src` in `index.html` if the extension changes. If a file is missing, the
company name is shown as a styled text placeholder instead.
