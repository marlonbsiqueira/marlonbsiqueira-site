# /assets/img — drop your images here

The site references these files. Replace each placeholder with your own:

| File | Purpose | Recommended size |
|------|---------|------------------|
| `profile.jpg` | Hero portrait (shown inside the gold ring) | Square, ≥ 800 × 800 px |
| `og-image.jpg` | Social link preview (LinkedIn / WhatsApp / X) | 1200 × 630 px |
| `favicon.png` | Browser tab icon | 64 × 64 px (or 32 × 32) |

Until `profile.jpg` exists, the hero shows a labelled placeholder pointing to this path.
As soon as you add the file with the exact name, it appears automatically — no code change needed.
